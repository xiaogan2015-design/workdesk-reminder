# 待办笔记 · Windows 工作待办与总结需求

## 使用场景

工作开始时打开工作台，查看当前待办和快到期的事项。处理完一项工作后勾选完成，必要时补记实际完成时间。收工时记录当天的工作，每周留一篇可以回看的总结。

## 首版功能与页面

| 编号 | 功能 | 操作与反馈 |
| --- | --- | --- |
| R1 | 工作台 | 打开应用即看到待处理、已逾期和今日完成数量，以及全部未完成事项。按截止时间排序，逾期排在前面，无截止时间的排在最后。可切换今日到期、逾期和已完成视图。 |
| R2 | 事项编辑 | 新建或编辑单项工作，标题必填，备注和截止时间选填。截止时间包含日期和时分。可以删除事项，删除前确认。 |
| R3 | 记录完成 | 在清单勾选完成，自动记录当前时间。可在编辑页补记或修正完成日期和时分。恢复待办会清除完成时间，并按现有截止时间重新安排提醒。 |
| R4 | 事项提醒 | 有截止时间的事项默认提前 30 分钟提醒，可为每项改动，填 0 表示到点提醒。到达计划时间时弹窗，可打开工作台。休眠或退出期间漏掉的提示，在唤醒或重启后补发给仍未完成的事项。 |
| R5 | 工作总结 | 支持日期选择器、日报与周报切换、正文输入及历史回看。每天可保存一条日报，每个周一至周日的自然周可保存一条周报，再次保存更新同一条。切换编辑对象前保护未保存内容。 |
| R6 | 总结提醒 | 日报默认每天 17:00 提示。周报默认关闭，启用后可选择星期和时间。日报与周报各自可关闭。弹窗直接打开对应的日期或周。当天已写好总结时跳过提示，漏掉的总结提示只在当天补发。 |
| R7 | 托盘与登录启动 | 关闭窗口后保留托盘和提醒。托盘可打开工作台或退出应用。登录 Windows 后自动启动可在提醒设置中开启，默认关闭。 |
| R8 | 复制与本地备份 | 日报和周报可逐篇复制为 Markdown 或另存 `.md`。工作台支持复制或导出完整事项清单，包含待办、已完成、备注和相关时间。设置可导出汇总 Markdown 或完整 JSON 备份。 |

视觉采用固定侧栏、浅色内容区和紫色强调色。主要操作「新建事项」放在工作台首屏。期限状态用文字和颜色同时区分。表单保留键盘焦点样式，长列表在内容区滚动。

从工作台点「新建事项」进入编辑表单，保存后回到原清单。工作总结页默认打开当天日报，切换周报时显示周一至周日的日期范围。提醒设置集中放置日报时间、周报时间和登录启动选项。

## 默认规则

- 应用使用 Windows 当前用户的本地时间显示和输入日期。日报的「每天」包含周末。周报提醒启用时预填周五 17:00。
- 「今日到期」按截止日期判断，今天已过截止时间的事项同时属于今日到期和逾期。逾期只统计未完成的事项。「今日完成」按实际记录的完成日期统计。
- 同一次截止计划只弹一次。变更截止时间或提前量后重新安排，单独修改标题或备注沿用原计划。已经完成的事项停止提醒。
- 正常退出后停止提醒。电脑再次可用时，工作台仍会显示逾期事项。

## 验收

| 验收项 | 操作 | 预期结果 |
| --- | --- | --- |
| A1 · 创建、排序与筛选 | 新建逾期、今天稍后到期、明日到期、无截止时间四条事项，再重启应用。 | 工作台按时间排序，四条都保留。今日到期和逾期筛选与各自日期规则一致。 |
| A2 · 完成和补记 | 勾选一条事项，再修改完成时间，最后恢复待办。 | 完成后移入已完成视图并记录时间。修改后展示补记时间。恢复后重回待办。 |
| A3 · 事项提醒 | 新建稍后到期的事项，将窗口关至托盘，等待提前提醒。点开提示，再退出并重启。 | 到点出现桌面提示，点击可打开工作台，同一个提醒计划不会重复出现。 |
| A4 · 日报与周报 | 写当天日报，分别从同一周的两天打开周报并更新，再回到历史日期。 | 日报按日期读写。同一周打开的是同一条周报，编辑后历史内容可回看。 |
| A5 · 总结提醒 | 分别设置即将触发的日报和周报时间。在其中一个排程触发前先保存对应总结。 | 未填写的周期弹窗可打开编辑页。已有内容的周期跳过弹窗。 |
| A6 · 打包和运行 | 双击打包后的 EXE，创建一项记录，关至托盘并从托盘重开。 | Windows 桌面正常打开，数据可用，托盘交互正常。仓库内提供构建与自测命令。 |
| A7 · 复制与备份 | 复制一篇含缩进和列表的总结，导出事项清单、汇总 Markdown 和完整 JSON。 | 总结格式得以保留，事项清单含截止与完成时间。文件写入指定的本机路径，JSON 可恢复事项、总结及提醒配置。 |
